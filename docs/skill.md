# swipe-decide

候補の一覧を URL にして人に渡すと、相手は1件ずつカードをスワイプして振り分けます。振り分け終わると、相手はそのまま貼り戻せる結果テキストをコピーできます。

サイト: https://konaito.github.io/swipe-decide/

## URL の作り方

```
https://konaito.github.io/swipe-decide/#items=<一覧>&title=<タイトル>
```

- `items`（必須）: 項目の一覧です。区切りは「、」「,」「，」改行のどれでもかまいません。混ぜても使えます。
- `title`（任意）: 画面の見出しと、結果テキストの1行目になります。
- どちらも `encodeURIComponent` でエンコードしてください。空白は `%20` にします。`+` は空白として読まれます。
- 前後の空白は切り落とします。空の項目は捨てます。重複はそのまま残します。
- 項目の中に区切り文字は書けません。
- 一覧は `#` の後ろ（fragment）に載せてください。fragment はサーバーに送られません。`?items=` も読めますが、サーバーのログに残ります。
- `items` が無いか空のときは、貼り付け欄が開きます。

例:

```
https://konaito.github.io/swipe-decide/#items=%E3%83%A9%E3%83%BC%E3%83%A1%E3%83%B3%E3%80%81%E3%82%AB%E3%83%AC%E3%83%BC%E3%80%81%E5%AF%BF%E5%8F%B8%E3%80%81%E3%81%86%E3%81%A9%E3%82%93&title=%E6%98%BC%E3%81%94%E3%81%AF%E3%82%93
```

これは `title=昼ごはん`、`items=ラーメン、カレー、寿司、うどん` です。

JavaScript で作るとき:

```js
const url = "https://konaito.github.io/swipe-decide/#items=" + encodeURIComponent(items.join("\n"))
  + "&title=" + encodeURIComponent(title);
```

## 操作

| 判定 | スワイプ | キー | ボタン |
| --- | --- | --- | --- |
| いいね | 右 | → | いいね |
| 却下 | 左 | ← | 却下 |
| 保留 | 下 | ↓ | 保留 |

左右は Tinder と同じで、右がいいね、左が却下です。直前の1件は「1件戻す」か、Backspace、z、↑ で戻せます。

## 結果テキスト

全部振り分けると、次の形のテキストが出ます。相手はこれをコピーか共有で貼り戻します。

```
昼ごはん
いいね: ラーメン、寿司
却下: カレー
保留: うどん
```

- 1行目はタイトルです。`title` が無いときはこの行がありません。
- 続く3行は必ず `いいね:`、`却下:`、`保留:` の順に並びます。
- 各行の項目は、渡した一覧の順に「、」でつなぎます。
- 該当が無い行は `却下:` のようにコロンで終わります。
- 読み取るときは、各行を最初の `:` で分け、後ろの前後の空白を取ってから「、」で分けてください。

## 状態の扱い

サイトは一覧も結果もどこにも保存しません。ページを読み直すと最初からになります。
